# 项目开发规范

## 语言使用规范
- 所有回复和交流使用**中文**
- 代码注释使用**英文**
- Git commit信息使用**英文**
- 回复要求简洁明确，避免冗余表达

## 代码风格规范
- C++代码遵循项目现有的代码风格
- 使用4空格缩进，不使用Tab
- 类名使用PascalCase，函数名使用camelCase
- 常量使用UPPER_SNAKE_CASE
- 文件名使用小写字母和下划线

## 架构模式
- 项目采用模块化架构，核心模块位于`src/infrastructure/`
- 使用SlotIPC进行进程间通信
- 网络通信基于asio库
- 遵循RAII原则进行资源管理

## 开发约定
- 新功能开发前先查看相关技术调研报告
- 性能敏感代码需要进行基准测试
- 跨平台兼容性考虑（Linux/Windows/Android）
- 优先使用项目已有的第三方库（位于`3rdparty/`目录）

## 文件组织
- 头文件放在对应的`.h`文件中
- 实现文件使用`.cpp`扩展名
- 测试文件放在对应模块的测试目录中
- 配置文件统一放在`assets/configs/`目录
